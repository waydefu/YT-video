# 動態 motif 工具組：旋轉、每頁轉場時長、六種可重用動態

> 版本 2026-11-14｜狀態：**SPIKE**。版面幾何有單元測試（A）；示範簡報的靜態畫面與轉場代理幀已自行檢查（B）；**C 層部分有證據：使用者用手機錄下示範簡報的放映（§4），Morph、旋轉與每頁時長都有播出；桌面版 PowerPoint 與匯出影片仍未驗證（NOT RUN）**。

來源：三支 Morph 範本宣傳影片的逐幀研究（研究文件在 PR #15，檔名 `PPTX-MORPH-TEMPLATE-STUDY.md`）。這裡只實作**通用機制**，不抄任何人的版面、形狀組合或配色。

## 1. 這次補進工具組的東西

| 項目 | 位置 | 做什麼 | 驗證 |
| --- | --- | --- | --- |
| 旋轉 | `scripts/pptx_world.py` | `Ctx.rect`／`oval`／`text`／`picture` 新增 `rot`（度，順時針，繞中心；負值自動換算） | 單元測試（XML 的旋轉值） |

| 代理旋轉 | `scripts/pptx_morph_proxy.py` | 中間幀插補旋轉，走**最短的弧**（350°→10° 經過 0°）；PowerPoint 的實際規則未文件化，這是假設 | 單元測試 |

## 2. 六個 motif（對應研究文件的 M 編號）

每個 motif 都是「同一批同名物件，換一個狀態」，兩頁用不同狀態繪製，Morph 就補間。

| motif | 函式 | 狀態 | 用途 |
| --- | --- | --- | --- |
| 同心圓環擴張（M1） | `ripple_radii`、`draw_ripple` | 進度 t（0..1） | 封面、章節開場 |
| 放射選單 → 縱列（M11） | `ring_layout`、`column_layout`、`draw_menu` | 點的排列（環或列）、啟動項 | **章節導覽**；縱列版加垂直換頁就是 M12 |
| 垂直換頁加常駐欄（M12） | 用既有 `pan_down` 加 HUD（抬頭）；HUD 依 `j` 畫出不同的啟動項 | 啟動項 | 章節、步驟頁 |
| 數字／標題滾動（M7） | `roll_layout`、`draw_roll` | 啟動項 | 章節編號 01 → 02 |
| 弧線滾輪清單（M8） | `wheel_layout`、`draw_wheel` | 啟動項 | 3–6 項的章節清單 |
| 卡片重排（M6） | `shuffle_layout`、`draw_cards` | 0 整齊／1 旋轉重疊／2 整齊（換內容） | 並列項換一批內容 |

示範簡報的做法：滾動項目全部同時畫出，非啟動的放在畫面外（上或下一步之遙），所以換頁時 Morph 把它們滑進來；畫面外的文字不算「要讀的文字」（`track=False`），不會觸發安全區警告。

## 3. 用法

```bash
python3 scripts/build_motion_kit_demo.py          # 輸出 build/motion-kit/motion-kit-demo.pptx
python3 scripts/pptx_validate.py build/motion-kit/motion-kit-demo.pptx --min-loops 0 --strict \
  --readable build/motion-kit/motion-kit-demo.readable.json
python3 scripts/pptx_morph_proxy.py build/motion-kit/motion-kit-demo.pptx build/motion-kit/proxy.pptx --steps 3
```

自己的簡報：`world.add(draw, "stay", dur=600)` 指定時長，建置時 `pptx_morph_patch.apply(draft, out, world.durations(900), hold)`。

## 4. 實機觀察（使用者的手機螢幕錄影，2026-11-14，47.5 秒）

錄影是手機錄下示範簡報放映（結尾出現「投影片放映結束。向前撥動畫面即可離開。」，我推論是 PowerPoint 手機版；**使用者未說明是哪個程式與版本**）。我用逐幀差異量出每個轉場的動作時長，再逐段看畫面：

| 項目 | 觀察 |
| --- | --- |
| Morph 是否播出 | 是。同心圓環擴張、放射選單的衛星圓移入縱列（中央圓縮成左上角的點）、垂直換頁（左欄不動）、數字滾動、卡片重排都是連續補間，沒有跳格或修復提示 |
| 每頁轉場時長 | **有生效**：動作長度 0.9／0.8／0.8／0.6／0.65／0.65／0.75／0.6／0.8 秒，對應設定的 1.1／0.9／0.8／0.6／0.6／0.6／0.7／0.6／0.8 秒（像素差異法，低動作量的轉場會被低估，±0.05–0.1 秒） |
| 旋轉 | **有補間**：卡片逐步轉到 ±7° 再轉回；數字 "02" 從下方帶傾斜進場、"01" 向上傾斜離場，平順 |
| 停留與轉場 | **Morph 時間是加在停留之外**：兩個轉場之間約 2.25–2.45 秒，設定的停留是 2.2 秒；整支 16 頁約 45.6 秒（16×2.2＋轉場 10.4）加結束畫面 ≈ 錄影長度 |
| 瑕疵一 | 標題頁 → 目錄頁（第 3→4 頁）：標題與同心圓淡出成幾乎空白約 0.2 秒，放射選單才淡入——因為兩頁沒有同名物件。可讓標誌圓與中央圓同名來改善 |
| 瑕疵二 | 放射選單 → 縱列的中途，標籤與新內容文字短暫重疊（約 0.25 秒），與轉場代理的預測一致 |

限制：這是手機播放，不是桌面 PowerPoint，更不是匯出影片；時長量測用像素差異，非精確。

## 5. 已知限制與風險

1. **旋轉在手機播放可見平順補間（§4）**；是否走最短弧、字級是否平滑、桌面版與匯出影片的表現仍未驗證。
2. 旋轉繞中心，`lx, ly` 仍是**未旋轉方框的左上角**；文字在旋轉方框內仍是原本的換行與對齊。
3. 弧線滾輪的項目字級隨距離縮小（34 → 20 pt），**不符手機優先的 30 pt**；只適合章節導覽，不適合承載要讀的內容。
4. 畫面外的物件可能在某些版本或匯出路徑被裁切或略過，未驗證。
5. 研究仍缺：圖片裁切補間、逐字／逐詞選項（`byWord`／`byChar`，補丁仍寫死 `byObject`）、柔光與漸層邊緣。
6. 範本研究以 9:16 影片為材料；本工具組以 16:9 為主，9:16 版另議。
