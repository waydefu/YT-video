# AI 訂閱額度比較：YouTube 旁白稿與分鏡（草稿，待使用者審核）

> 版本 2026-11-07｜狀態：**RESEARCH / 草稿**。這是旁白與分鏡的**第一版**，還沒有改任何簡報。**所有數字取自使用者文件 v5.1（快照 2026-11-03），沒有向供應商重新核對；發布前必須逐項重查。**

## 1. 已確認的方向（使用者 2026-11-07 回覆「沒問題」）

| 項目 | 採用 |
| --- | --- |
| 觀眾 | 一般人（白話、少術語；術語第一次出現就用一句話解釋） |
| 長度 | 約 10 分鐘（旁白約 2,200 字，每分鐘約 220 字；實錄後再調） |
| 手機優先 | 畫面字級 **30 pt 以上**、一頁一個重點、最多 4 行；細節交給旁白（門檻為估算值，未在手機上驗證） |
| 旁白 | 待定（自己錄或合成語音）；稿子兩者通用 |
| 結構 | 鉤子 → 先講結論 → 逐一展開 → 自己怎麼測 → 檢查清單 |

## 4. 發布前必做（不做不要上傳）

1. **逐項向各供應商官方頁面重新核對所有數字**（價格、倍率、方案名稱、限制）；更新 `scripts/ai_subscriptions_data.py` 與快照日期。
2. 標題與說明欄標示「資料截至」；說明欄附來源連結與「非贊助、與各公司無關聯」聲明；置頂留言放更正記錄。
3. Logo：Cursor、OpenCode 與其他平台的呈現要一致（建議全部改文字＋色塊）。
4. 在 Windows 版 PowerPoint **先匯出一小段 1080p 影片**，檢查 Morph 是否保留、3.7× 放大是否糊掉或掉格；若不保留，需要你同意改用螢幕錄製。
5. 字幕檔（SRT）與縮圖另外製作；若使用合成語音，YouTube 是否要求揭露我**沒有查證**，上傳前請看最新政策。

## 5. 需要使用者決定

- 鉤子與標題用語（是否太口語或太聳動）。
- 是否同意移出「模型能力」與「API 贈額」兩頁。
- 旁白自己錄還是合成語音；是否在旁白中加入你自己的實測（文件第 4 章的個人用量我沒有放入）。
- 同意後我才會動簡報：字級放大、拆成約 40–60 頁、導讀高亮、安全區與字幕留白、讀秒數表的建置選項。
