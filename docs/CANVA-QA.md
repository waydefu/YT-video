# Canva 視覺／聲音／匯出驗收清單

> 本文件是**驗收規則**，並非本次已經完成的 Canva 影片測試。遵守 `AGENTS.md`：主體 10% 安全邊、文字 15% 安全邊、最終 1920×1080 / 16:9 / 24fps（正式影片管線），原稿 / preview / final 必須清楚標記。

## 1. 製作前 Gate 0

- [ ] 交付類型明確：Canva 原稿 / PPTX / MP4 / 動態草稿，不混淆。
- [ ] 所有內容分「來源已查」「本人實測」「合理推估」「不確定」。
- [ ] 素材來源、連結、授權、商用條款與素材修改權已登錄。
- [ ] 影片比例 16:9，主體 10% 與標題 15% 安全區可視化。
- [ ] 拆解鏡頭的空間錨點 / 閱讀停留 / 轉場意圖。
- [ ] 字體可顯示完整繁體中文，標題、字級及對比規格已規劃。

## 2. Canva 片段 Gate 1（需人工觀看）

- [ ] 先只做 10–30 秒測試段，檢驗 Match & Move 與同物件連續性。
- [ ] 不同場景切換不突然改變物體大小、角度、色彩或場景方位。
- [ ] 轉場前 / 中 / 後各截至少一格，無跳位、抖動、破洞、文字失焦、遮罩閃爍。
- [ ] 每段有明確閱讀時間，觀眾不需暫停仍能理解核心訊息。
- [ ] 物件沒有互相遮擋關鍵字，繁中文字型、行距、連字與符號可讀。
- [ ] 觀察一般播放速度與手機全螢幕；不能只看 Canva 編輯器。
- [ ] 確認畫面是實際錄製 / 已授權資料，示意圖明確標註。
- [ ] 沒有假裝「2.5D 平面視差 = 真 3D、物理模擬」。

## 3. 輸出 Gate 2

Canva 出口：Share→Download→MP4；先查看目前方案解析度限制。官方沒有在查到的匯出頁面明示原生 fps 可自訂，不得推定必然是 24fps。

本地有 FFmpeg / FFprobe 時：

```bash
ffprobe -v error -show_entries format=duration:stream=index,codec_type,codec_name,width,height,r_frame_rate,avg_frame_rate,sample_rate,channels -of json input.mp4
```

**只在源 fps / 類型確認後**，若需按此 repo 主片頭交付規格轉成 24fps，可用類似：

```bash
ffmpeg -i input.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=24" -c:v libx264 -pix_fmt yuv420p -crf 18 -preset medium -c:a aac -b:a 192k output-24fps.mp4
```

注意：上述命令只是**規格化轉碼示例**；不能解決來源轉場卡頓、字幕錯字、畫面品質不足、音源侵權。若來源影格率不同，可能出現重複 / 捨棄影格，需人工比對原版及轉碼版；源音軌不存在時另行處理。

可用現有影片驗證工具（若契約吻合）：`python3 scripts/validate_media.py <path>`，但自動通過**不代表構圖驗收完成**。

## 4. 聲音 Gate 3

- [ ] 旁白可清楚辨識，不被音樂蓋過；檢查左右聲道與變化。
- [ ] SFX 與視覺動作對齊，爆點不失真、不高頻刺耳。
- [ ] 音訊淡入淡出在正確位置，不把「圖像 Fade」當音訊 Fade。
- [ ] 若用 Canva 付費音樂，具備合法授權 / 驗證資料；Popular Music 不直接用於營利發布。
- [ ] 無突然的靜音、剪斷尾音、音樂重置和跨場景不合理聲音跳切。

## 5. 最終 Gate 4（發布需另行核准）

- [ ] 桌機 100% 觀看一遍，手機全螢幕觀看一遍。
- [ ] 主要轉場逐格檢查，與參考片比較**節奏和連續邏輯**而非直接複製素材。
- [ ] 所有引用、安裝步驟、成本、版本與限制逐項複核。
- [ ] MP4 / Canva 原稿 / 來源 / 權利資料與 QA 結果可回溯。
- [ ] 報告有列：`資料查證`、`Canva 原稿實作`、`影片輸出`、`自動化測試`、`人工視覺 / 聲音驗收` 各自狀態。
- [ ] 使用者批准後才合併、發布或進一步動用尚未授權的付費工具。
