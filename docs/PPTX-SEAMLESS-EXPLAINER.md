## 1. 設計模型：一個連續世界，每頁只是鏡頭位置

所有頁面的內容放在**同一個世界座標**裡，以**面板（panel）**表示；每張投影片只是「鏡頭對準哪個面板」。跨頁同名（`!!NAME`）的物件由 Morph 連續移動與縮放，視覺上就是一鏡到底。

`scripts/build_science_explainer.py` 的樣片（主題：為什麼天空是藍色）用到三種手法：

| 轉場 | 手法 | 世界座標做法 | 縮放比 |
| --- | --- | --- | --- |
| 1→2 | **Zoom-through（鑽進視窗）**：下一頁就住在上一頁畫面裡的一個小視窗 | 面板 B 以 0.2925 倍縮小嵌在標題頁（面板 A）的「視窗框」中；第 2 頁鏡頭對準 B | 3.42× |
| 2→3 | **平移（Pan）**：沿牆面橫移到隔壁視窗 | 面板 C 與 B 並排、同大小、相距 5.05 世界單位；縮放不變只移動 | 1× |
| 3→4 | **拉遠揭露（Pull-back reveal）**：剛才的圖原來是掛在更大場景牆上的畫框 | 場景 D 只在第 4 頁存在（Morph 淡入），其畫框區域剛好等於 C 的位置與大小；C 疊在 D 之上 | 2.96× |

這些手法取自對參考影片的逐幀檢視（見 `PPTX-LIVE-MOTION.md` §1）：報紙上的灰色圖框被鑽入、放射圖其實是牆上畫框。

### 規則（來自實作與代理幀檢查）

1. **每一步縮放比控制在約 3.5× 以內。** Morph 逐物件線性插值位置與大小（Microsoft 文件未載明確切緩動，**以下為合理假設，需實播驗證**），縮放比太大會在後段「突然變大」。更大跨度請拆成多步。
2. **字級補償**：面板內文字大小＝設計字級 × 面板縮放 × 該頁鏡頭縮放，這樣每個「被對準」的面板在其頁面上是設計字級（樣片：標題 40 pt、內文 24–28 pt）。被縮小嵌入的視窗在其他頁只是「預覽縮圖」，文字小是預期的。
3. **單一圖形不超過約 56 英吋**（PowerPoint 介面上限，放大後容易超過）：大背景要切塊；**接縫放在任何一頁都看不到的地方**（樣片放在兩個視窗之間、廣角畫面之外；實際做過才發現接縫在廣角畫面會出現一條細線）。
4. **目的頁才存在的物件**（如 D）在 Morph 中淡入；**目的頁的 z 順序決定疊放**，所以讓 C 排在 D 之後。
5. 所有會 Morph 的物件使用唯一 `!!` 名稱，同頁不得重複（驗證器會查）。
6. **停留時間 `--hold` 對應旁白長度**：樣片預設 4.8 秒只是展示；實際製作以每頁旁白時間設定（`advTm`）。
7. **環境動態（選用）**：太陽呼吸、分子環繞、雲飄移，幅度要小、週期整除停留時間（驗證器會警告）；不需要時 `--no-ambient`。科普內容要讀，動態不能搶焦點。

## 3. 新主題的製作流程（G0–G5 的簡報版）

1. **腳本**：每頁一個要點與旁白時間；事實與來源先寫進台帳（§5）。
2. **鏡頭分鏡**：每個轉場選一種手法（鑽進／平移／拉遠揭露），算出縮放比（§1 規則 1）。
3. **版面**：每個面板 16:9、文字 ≥ 24 pt（內文）/ ≥ 40 pt（標題）、在 5% 邊緣安全區內。
4. **建置**：面板函式 + 鏡頭位置；`!!` 命名；大背景切塊避縫。
5. **A 層**：單元測試＋驗證器（`--strict`）。
6. **B 層**：LibreOffice 轉 PNG 逐頁看；再跑 `pptx_morph_proxy.py` 看中間畫面（有無空洞、閃現、物件穿過文字）。
7. **C 層（必要）**：在支援 Morph 的 PowerPoint 放映，看開檔無修復提示、轉場連續、無跳位。
8. **匯出測試（必要）**：PowerPoint「匯出成影片」1080p，檢查 Morph 是否被保留、有無掉格、凍結段（`ffmpeg -vf freezedetect`）。
9. **D / E**：桌面與手機可讀性；事實、圖像、字型授權。
10. **G5**：使用者看過才升級狀態；**不自動合併／發布**。

| 層 | 狀態 | 證據 |

| B 轉場代理 | 完成（13 張中間幀，線性插值＋smoothstep） | 三段轉場的中間畫面沒有空洞或閃現；1→2 的標題在轉場中被放大推出；3→4 中途 C 暫時蓋住 D 的標題（C 縮小後消失） |
| C PowerPoint 實播 | **BLOCKED / NOT RUN** | 無 Microsoft PowerPoint |
| 匯出影片 | NOT RUN | — |
| D 桌面／手機 | NOT RUN | — |
| E 內容與授權 | 授權 PASS（原創向量）；**事實待使用者審核** | §5 |

**代理的限制**：不含真實緩動、文字處理、漸層淡入（代理中漸層不淡入）；**只能否決，不能證明。**

**自查發現的三個最可能的問題**：
1. **真實 PowerPoint 的緩動與文字縮放未知**：Morph 對大字級變化的處理可能與代理不同（可能淡入淡出而非連續縮放）。
2. 嵌入視窗的縮圖文字在廣角頁只是小色塊；若希望觀眾在廣角就看得懂，需另設計。
3. 美術為簡單向量，科普頻道若要更高質感，需插圖／示意圖素材（需授權）。

## 6. 已知風險與未驗證項

- **PowerPoint 匯出影片時 Morph 是否保留**：搜尋到的非官方文章表示 Morph／複雜動畫匯出可能失敗或掉格（可信度低，需自行試匯出）。若不保留，備案是用螢幕錄製（OBS）錄放映，這是另一個製作流程，需使用者同意。
- Morph 時長上限、緩動：未能由官方文件確認。
- 大面積背景與大縮放比造成的渲染負擔（低階電腦放映可能掉格）。
- 嵌入視窗內文字縮圖在不同 PowerPoint 版本的繪製。
