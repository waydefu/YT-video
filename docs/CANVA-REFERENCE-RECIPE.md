# 參考影片動態拆解與 Anatomy 範例分鏡

> 參考：使用者在對話中提供的 18.27 秒 / 30fps Canva 錄影。當時逐格分析報告為 545 影格；**原影片不儲存、不轉傳到此 repo**。下表是觀察與初步技術推定，不代表看得到作者的工程或實際 Canva 設定。

## A. 參考片：可學與不可學

| 時間（約） | 觀察 | 可以學到的製作邏輯 | 注意 |
| --- | --- | --- | --- |
| 0–6.2s | 編輯畫面 / 複雜線條圖層 | 素材預先分層、形成連續場景 | 多數是編輯過程，不是正式鏡頭 |
| 6.3–8.2s | 報紙主視覺逐步展示 | 先建立場景，再給觀眾閱讀 | 小字在手機上不容易看 |
| 8.3–9.4s | 報紙鏡頭推近紅色地圖 | 共用視覺錨點，跨頁推進 | 若圖像不相同會跳位 |
| 9.4–11.4s | 地圖與人物定鏡 | 靜止，讓內容進入觀眾理解 | 不可一味追求快 |
| 11.5–12.7s | 鏡頭下移至海報 | 「移動視線」而非換片 | 必須保留空間方位 |
| 12.8–14.5s | 海報強調 | 高對比、單一核心訊息 | 避免無關樣板文案 |
| 14.5–15.6s | 拉遠，海報變成牆上畫框 | **最有價值**：局部物件揭露完整場景 | Canva 2.5D 能模擬，不等於真 3D |
| 15.6–17.3s | 畫框帶到房間 / 人物 | 不同事件同一視覺世界 | 需先規劃背景素材 |
| 17.3–18.27s | 向下帶到新報紙 | 運動延續，帶出下一節 | 結尾必須給下段銜接 |

### 動態品質最低線

- 不只是套 Fade；每次轉場應有「保留物件 → 移動鏡頭 → 揭露信息」的因果。
- 鏡頭在動時文字不要滿屏亂飛，停住要讓觀眾閱讀。
- 參考影片的優點是空間關係與節奏；細小正文、樣板殘文、畫面可讀性不足不能照抄。
- 不能只以自動分辨率測試宣稱達到參考片品質，必須人工對比連續影片。

## B. Anatomy 題材（**示範規劃，未驗證所有工具功能**）

**定位**：工具研究與使用指南，不是宣傳片；呈現怎麼裝、怎麼用、強項、弱點、適用與不適用族群。安裝指令需於製作時從官方 repo 最新 README 核對，不可在視覺腳本中虛構。

| 鏡頭 | 預估長度 | 畫面內容 | 轉場設計 / 前後錨點 |
| --- | ---: | --- | --- |
| 01 鉤子 | 4s | 「文字怎麼變成可互動的圖解？」機械零件特寫 | 從零件特寫慢慢拉遠，露出完整模型 |
| 02 是什麼 | 5s | 工具定位、能做什麼與不能做什麼 | 模型外框化為説明卡；保留同色標線 |
| 03 環境 | 6s | 安裝前必備條件，官網與平台支援 | 介紹卡變成模擬終端機框（實際畫面需另核對） |
| 04 安裝 | 8s | 官方安裝步驟、驗證成功狀態 | 鏡頭推入可閱讀的命令列；先定鏡 |
| 05 基本操作 | 10s | 真實輸入、輸出、檔案去向 | 終端機結果沿視覺連線引導到成果展示 |
| 06 結果檢視 | 8s | 旋轉 / 局部放大 / 模型交互（僅實際支援時展示） | 同一畫面特寫展開；交互未測不得裝作成功 |
| 07 優點 | 7s | 表達結構、教學效率、可互動性（需有例證） | 模型分成三個可以指示的區域 |
| 08 缺點 | 8s | 不支援的功能、畫質 / 精度風險、成本 / 編輯限制 | 三區域退回模型，揭露有明確標註的限制 |
| 09 適合誰 | 7s | 開發者、教育工作者等依證據與操作成本判斷 | 左側代表適合的情境，右側代表不適合 |
| 10 結論 | 6s | 不同需求的條件式結論 + 來源 | 拉遠到整張工作桌 / 資料來源清單 |

總長約 **69 秒**，只是短篇動態簡報段落，不是整部影片時長承諾。實際資訊調研不充分就先做教學腳本，不造假功能，不能靠華麗動畫掩飾未測的事實。

## C. 每段轉場要交付的資訊

每段至少登錄：
- `scene_id` / 上下段意圖與關鍵訊息
- `anchor` 固定視覺物件（前段與後段同一物件）
- `type`：match-move / object-path / hold / cut / footage / Blender
- `duration_s`、`read_hold_s`、是否有配樂 / 音效
- `evidence`：官方畫面、實際跑過的 demo、未驗證示意
- `assets_rights`：可發布 / 僅參考 / 不可用
- `review`：手機可讀、轉場有無跳位、音畫同步、權限 / 授權

**畫面原則**：寧可用 8 段真正順暢的運鏡，不要 20 段由模板轉場拼湊的畫面。影片最後必須交由使用者人工審核。
